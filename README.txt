E Home Elektro-Kalkulator iPhone PWA

Для установки на iPhone разместите все файлы папки на HTTPS-хостинге (например, GitHub Pages), откройте адрес в Safari, выберите Поделиться -> На экран «Домой».
Открытие index.html из приложения Файлы НЕ устанавливает PWA.
Данные цен сохраняются отдельно в Safari на iPhone. Перенесите цены через JSON резервную копию из компьютерной версии.
Для сохранения данных не используйте приватный режим и не очищайте данные сайта.
